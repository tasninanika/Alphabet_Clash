# Alphabet Clash

## Overview
**Alphabet Clash** is a fun and interactive word game where users type in random words that appear on the screen. The goal is to type the words as quickly as possible to score points. You have 5 lives, and the game ends when all lives are lost. After the game ends, your total score is displayed.

## Key Features
- Random words appear on the screen that need to be typed correctly.
- Each correct word typed adds one point to the score.
- You have 5 lives; the game ends when all lives are lost.
- Real-time updates of the score as you type.
- Total score shown at the end of the game.
- Responsive, interactive, and visually engaging UI using Tailwind CSS.

## Technologies Used
- **HTML5**: For structuring the page and displaying the game elements.
- **Tailwind CSS**: For styling and making the game interface responsive.
- **JavaScript**: For handling game logic, generating random words, and updating the score.
  
## How to Use
1. Visit the live website: [Alphabet Clash](https://alphabet0clash.netlify.app)
2. Start typing the random words that appear on the screen.
3. Each time you type a word correctly, your score increases by one.
4. You have 5 lives—each incorrect word typed will reduce your remaining lives.
5. The game ends when you lose all 5 lives, and your total score will be displayed.
